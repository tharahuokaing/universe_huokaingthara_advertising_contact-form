## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_advertising_contact-form`** is the official client onboarding and campaign inquiry interface for **UNIVERSE HUOKAING THARA Group**. Designed for brands, sponsors, and marketing agencies, it streamlines communication with our executive marketing desk by capturing target media channels, preferred sponsorship tiers, launch schedules, and campaign briefs.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🎯 Multi-Channel Campaign Selector:** Interactive pill-style checkboxes allowing advertisers to target one or multiple platforms simultaneously (*Movies, Ghost Stories Khmer, Pranks, Music Video, and Web Banners*).
* **✅ Real-Time Bilingual Form Validation:** Client-side input validation with localized Khmer and English error prompts for contact names, brand details, phone/Telegram handles, and email addresses.
* **🧾 Instant Confirmation Receipt Modal:** Automatically generates a unique tracking reference ID (`UHT-AD-XXXXXX`) and displays a complete summary modal upon successful inquiry submission.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle between Khmer-only, English-only, or dual-language display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.
